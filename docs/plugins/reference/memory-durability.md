# Memory Durability plugin

Aurelius memory-plane durability watchdog: a queryable health tool plus a managed cron watcher that alerts Slack when memory copies diverge, CORE.md goes stale, the bus stalls, or the vault falls behind.

## Distribution

- Package: `@openclaw/memory-durability`
- Install route: included in OpenClaw

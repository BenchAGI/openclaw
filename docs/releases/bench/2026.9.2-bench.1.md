# OpenClaw 2026.9.2 — Bench release 1 (draft)

**Status:** draft notes; no tag, package, GitHub release, or tap bump exists yet.
Fill the receipt block before publishing.

**Base:** fork `main` merged forward with upstream `v2026.9.2` — PR #125
(`feat/main-merge-upstream-2026.9.2`, head `0cfef0ea12` at the time of writing;
the merge result on `main` is the source commit once it lands). No release is
cut from the transitional `bench-runtime-2026.9.2` branch (Cory, 2026-09-06).

## What customers get

- **Upstream 2026.9.2** in full: the current model catalog and provider
  support, Mermaid diagrams in chat, the reworked Control UI header, four new
  upstream themes, safer update recovery, and the long-history performance
  work. See the upstream notes for `v2026.9.1` and `v2026.9.2`.
- **BenchAGI Aurelius Vault shell.** The Control UI a customer's Gateway serves
  is now branded BenchAGI Aurelius Vault: title, manifest, About, approval page,
  and the built-in assistant ("Ask Aurelius"). The Bench theme (dark and light)
  is the default for fresh profiles; existing profiles keep their stored theme.
  The Aurelius mascot replaces the lobster/claw across the shell.
- **Trusted-ingress boundary.** `gateway.auth.mode = "trusted-proxy"` with
  named roles, `users.list` readback, and `config.get` revision parity are the
  contract the Bench relay proxy and the Vault desktop rely on. Verified on the
  transitional line by the ADR-0005 proof (15/15); re-run against a Gateway
  built from the release commit on `main` before any release is cut.
- **The fork's own Gateway work, carried forward.** Everything that was on fork
  `main` before the merge stays on the customer line (the cloud-brain
  `chat.send` bridge from #82, Slack delivery logging from #109, and the rest of
  the fork history); the merge PR's `MERGE-NOTES.md` is the authoritative list
  of what moved and where.

## What did not change

- Gateway, relay, and auth code is upstream 2026.9.2 plus the fork's existing
  commits as re-homed by the merge; the branded-shell commits touch `ui/`, one
  release-validation test fixture, and the Bench CI lane. Strings that name the
  OpenClaw runtime, update channels, and upstream apps are unchanged; the
  license credit is unchanged.
- The relay's OAuth proxy listener stays inert until an operator activates it.

## Operator notes

- **One build, one version.** 2026.9.2 admits a same-host Control UI only when
  its `client.buildId` matches the Gateway's runtime build id. The branded UI
  ships inside the Gateway bundle from the same commit; never serve it from
  elsewhere for customers.
- **Config re-homes on this line (upstream change).**
  `agents.defaults.memorySearch.*` moved to `memory.search.*`; the tier-1 and
  reranker settings now live at `memory.search.query.tier1` and
  `memory.search.query.reranker`. Boxes carrying the old keys must be migrated
  before the update lane moves them; the relay activation runbooks need that
  step.
- **Cloud-brain chat bridge.** The `chat.send` bridge now lives in
  `src/gateway/server-methods/chat-send-agent-dispatch.ts` (`cloudAuth` on
  `ChatSendParamsSchema`, `gateway.benchCloud` in the config schema). A live
  Vault chat smoke against a Gateway built from the release commit is a
  release gate before the `v2026.9.2-bench.1` tag.
- **Fresh proxied subjects hold no scopes** until `users.setRole` assigns the
  reviewed role; activation runbooks must include that step.
- Customers today run `v2026.6.11-bench.1` through the tap. This is the first
  release on a newer line since then; expect the relay update lane's cohort and
  soak gates to apply.

# OpenClaw 2026.9.2: Bench release 1 (draft)

**Status:** draft notes; no tag, package, GitHub release, or tap bump exists yet.
Fill the receipt block before publishing.

**Base:** fork `main` merged forward with upstream `v2026.9.2` in PR #125
(`feat/main-merge-upstream-2026.9.2`, merge commit `36db53c016`; the
branded-UI PRs remain separate reviewed inputs before a customer tag). No
release is cut from the transitional `bench-runtime-2026.9.2` branch (Cory,
2026-09-06).

## What customers get

- **Upstream 2026.9.2** in full: the current model catalog and provider
  support, Mermaid diagrams in chat, the reworked Control UI header, four new
  upstream themes, safer update recovery, and the long-history performance
  work. See the upstream notes for `v2026.9.1` and `v2026.9.2`.
- **BenchAGI Aurelius Vault shell.** The Control UI a customer's Gateway serves
  is now branded BenchAGI Aurelius Vault: title, manifest, About, approval page,
  and the built-in assistant ("Ask Aurelius"). The Bench theme (dark and light)
  is the default for fresh profiles; existing profiles keep their stored theme.
  The Aurelius mascot replaces the lobster/claw across the shell.
- **Trusted-ingress boundary.** `gateway.auth.mode = "trusted-proxy"` with
  named roles, `users.list` readback, and `config.get` revision parity are the
  contract the Bench relay proxy and the Vault desktop rely on. Verified on the
  transitional line by the ADR-0005 proof (15/15); re-run against a Gateway
  built from the release commit on `main` before any release is cut.
- **The fork's own Gateway work, carried forward.** Everything that was on fork
  `main` before the merge stays on the customer line (the cloud-brain
  `chat.send` bridge from #82, Slack delivery logging from #109, and the rest of
  the fork history); the merge PR's `MERGE-NOTES.md` is the authoritative list
  of what moved and where.

## What did not change

- Gateway, relay, and auth code is upstream 2026.9.2 plus the fork's existing
  commits as re-homed by the merge; the branded-shell commits touch `ui/`, one
  release-validation test fixture, and the Bench CI lane. Strings that name the
  OpenClaw runtime, update channels, and upstream apps are unchanged; the
  license credit is unchanged.
- The relay's OAuth proxy listener stays inert until an operator activates it.

## Operator notes

- **One build, one version.** 2026.9.2 admits a same-host Control UI only when
  its `client.buildId` matches the Gateway's runtime build id. The branded UI
  ships inside the Gateway bundle from the same commit; never serve it from
  elsewhere for customers.
- **Config re-homes on this line (upstream change).**
  `agents.defaults.memorySearch.*` moved to `memory.search.*`; the tier-1 and
  reranker settings now live at `memory.search.query.tier1` and
  `memory.search.query.reranker`. Per-agent overrides moved with the agent
  table itself: upstream replaced `agents.list[]` with `agents.entries`, so an
  override now lives at `agents.entries.<id>.memory.search.*`. The reranker
  SecretRef targets changed accordingly — `memory.search.query.reranker.apiKey`
  and `agents.entries.*.memory.search.query.reranker.apiKey`; the old
  `agents.defaults.memorySearch.query.reranker.apiKey` target is gone from the
  registry and the secretref matrix, so any box that stored that key through
  `openclaw secrets` must re-target it. Boxes carrying the old keys must be
  migrated before the update lane moves them; the relay activation runbooks
  need that step.
- **Tier-1 retrieval-at-start** (`memory.search.query.tier1`) pays its
  embedding-provider discovery only at search time when the flag is on; with
  the flag off, bootstrap turns never load a provider runtime. The
  merge-forward (PR #125, fix `13a580ba97`) removed an eager provider load from
  the disabled path that hung every bootstrap turn on Linux hosts.
- **Cloud-brain chat bridge.** The `chat.send` bridge now lives in
  `src/gateway/server-methods/chat-send-agent-dispatch.ts` (`cloudAuth` on
  `ChatSendParamsSchema`, `gateway.benchCloud` in the config schema). A live
  Vault chat smoke against a Gateway built from the release commit is a
  release gate before the `v2026.9.2-bench.1` tag; it must confirm
  typing/lifecycle cleanup and the assistant transcript append after a
  remote-brain turn (upstream's admission/finalize lifecycle owns cleanup
  now; the fork's own lifecycle broadcasts were not carried), not only that a
  reply arrived.
- **Fresh proxied subjects hold no scopes** until `users.setRole` assigns the
  reviewed role; activation runbooks must include that step.
- Customers today run `v2026.6.11-bench.1` through the tap. This is the first
  release on a newer line since then; expect the relay update lane's cohort and
  soak gates to apply.

## Control UI parity (`feat/bench-vault-theme-parity`)

Follow-ups to #123 so the served Control UI matches the Vault's design language
inside the desktop shell. UI-only: no Gateway, auth, trusted-proxy, or protocol
behaviour changes beyond one new value in the profile-storable typeface tuple.

- `4af2a58d34` feat(ui): bundle Inter as the Bench families' body face — Inter
  Variable (latin, latin-ext; SIL OFL 1.1, licence beside the files) ships
  under `ui/public/fonts/`, `inter` joins the typeface tuple, and the four
  Bench palettes set `--font-body: "Inter"` with the system fallbacks. Display
  faces (Space Grotesk / Lora) and the JetBrains Mono code face are unchanged;
  profiles with a stored typeface override keep it.
- `a365529bcd` style(ui): record the Vault ink and chalk ramp behind the Bench
  palette — comment-only; the values already matched the Vault's
  `bench-tokens.css`. `--muted` stays lifted above the Vault's chalk-4 for the
  4.5:1 muted-token tests; `--ring` stays Infrared (5.4:1 on `--bg`).
- `8072906f92` feat(ui): vendor the accepted gravity fabric head and light it
  outside the Vault — `ui/src/lib/gravity-fabric.ts` is BenchAGI/aurelius
  `apps/aurelius-vault/app/src/gravity-fabric.ts` @ `7e987ce5` (five `?? 0`
  narrowings for the fork's `noUncheckedIndexedAccess`; oxfmt/oxlint skip the
  file), and the host chunk that #123 never imported is now deferred from
  app-root. The fabric mounts for Bench families with "Background motion" on,
  except under `<html data-bench-host="aurelius-vault">`: inside the desktop
  Vault its own fabric is the one live loop and the toggle is hidden. The
  toggle keys on availability, so switching it off no longer hides it.

Operator note: nothing here changes what the relay installs or restarts; the
fabric is a deferred chunk that honours `prefers-reduced-motion`, and the Vault
embed sees no second animation loop.
